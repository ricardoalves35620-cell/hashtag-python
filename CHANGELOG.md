# Histórico de versões

Este arquivo resume as mudanças que afetam quem usa ou mantém o projeto. As notas detalhadas continuam em `docs/RELEASE_NOTES_*.md`.

## 10.25.0

- Formação completa com 69 fases: 54 obrigatórias e 15 opcionais de IA local.
- Learning Engine com jornadas pedagógicas, prática verificada, avaliações e mini projetos.
- Sincronização de progresso, histórico, diários, projetos e preferências entre dispositivos.
- Portfólio com projetos integradores de fundamentos, Python profissional, engenharia, dados e IA local.
- Modo visitante com persistência local.
- PWA, execução isolada de Python e suporte bilíngue.

## Marcos anteriores

- **4.0:** trilha de dados, Machine Learning e IA local.
- **3.0:** Python avançado e engenharia de software.
- **2.0:** formação de Python profissional.
- **1.4:** Base Zero e alfabetização digital.
- **1.3:** aprendizagem adaptativa e revisão espaçada.
- **1.2:** execução Python isolada e avaliador verificado.

Para detalhes de cada sprint e do Learning Engine, consulte a pasta `docs/`.
